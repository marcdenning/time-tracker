# Time Tracker

> Front-end web app for tracking time spent on multiple efforts.

This project is built with [Vite](https://vite.dev/).

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode with the Vite dev server.
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

The page will hot-reload as you make edits.

### `npm test`

Launches the [Vitest](https://vitest.dev/) test runner in interactive watch mode.

Run `npm test -- run` for a single non-interactive run (used in CI).
Filter by test name with `npm test -- -t "test name"`, or by file with `npm test -- formatDuration`.

### `npm run build`

Builds the app for production to the `dist` folder.
It bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include content hashes.
Your app is ready to be deployed!
